# Сборка установщика «AZS Monitoring»

Превращает Python-проект в установщик `AZS-Monitoring-Setup.exe`, который
любой человек ставит в два клика — Python и зависимости ему не нужны.

## Что получится

- `dist\AZS-Monitoring\` — самодостаточная папка с `AZS-Monitoring.exe`
- `installer_output\AZS-Monitoring-Setup.exe` — установщик с ярлыками
  (меню Пуск + рабочий стол) и деинсталлятором

## Требования (один раз)

1. **Inno Setup** (компилятор установщика):
   ```powershell
   winget install -e --id JRSoftware.InnoSetup
   ```
2. PyInstaller ставится автоматически скриптом сборки.

## Сборка (одна команда из корня проекта)

```powershell
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

Скрипт сам: поставит PyInstaller → соберёт `.exe` → найдёт Inno Setup →
соберёт установщик.

> ⚠️ Сборка тяжёлая: с CUDA-версией PyTorch результат — несколько ГБ,
> сборка идёт долго и требует свободного места на диске. Это нормально.

## Как работает на компьютере пользователя

- **GPU/CPU автоматически.** torch использует видеокарту NVIDIA, если она есть,
  иначе переключается на CPU. Отдельные сборки не нужны.
- **Данные пользователя** (зоны, БД, инциденты, настройки) пишутся в
  `%LOCALAPPDATA%\AZS-Monitoring\`, а не в Program Files. При первом запуске
  туда копируются дефолтные конфиги и создаётся шаблон `.env`.
- **Уведомления.** Токен Telegram и почта НЕ зашиты в установщик. Каждый
  пользователь вписывает свои данные в `%LOCALAPPDATA%\AZS-Monitoring\.env`.
- **EasyOCR** при первом распознавании номеров докачивает свои модели из сети
  (нужен интернет на первом запуске этой функции).

## Отладка сборки

Если `.exe` падает при запуске без сообщений — временно поставь в
`AZS-Monitoring.spec` параметр `console=True`, пересобери и запусти `.exe` из
консоли, чтобы увидеть traceback. Чаще всего не хватает «скрытого» импорта —
его добавляют в `hiddenimports` в спеке.

## Структура файлов сборки

| Файл | Назначение |
|------|------------|
| `AZS-Monitoring.spec` | конфигурация PyInstaller (что и как паковать) |
| `packaging\installer.iss` | скрипт Inno Setup (установщик + ярлыки) |
| `packaging\build.ps1` | сборка «в одну кнопку» |
| `app_paths.py` | разрешение путей (ресурсы vs пользовательские данные) |
